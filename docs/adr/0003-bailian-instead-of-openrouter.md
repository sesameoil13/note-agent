# AI 服务改用阿里云百炼（北京地域），一家服务一份 Key

用户不再使用 OpenRouter，改用阿里云百炼（通义千问，北京地域）。仍是一家服务、一份 Key：文字整理固定用 qwen-plus，录音转写用 qwen3-asr-flash 并关闭数字规整（ITN），费用以人民币结算，继续计入共享月预算。DeepSeek 官方接口没有语音转写，因此未被选用。

探测（issue #34）确认：同一把北京地域 Key 可完成文字与转写；App 录音的 .m4a 可直接提交；严格 json_schema 输出可用；响应带 id 与用量（tokens、秒）；列出模型可免费检测 Key。代价有三：单次转写不超过 5 分钟，超过 4.5 分钟的录音须在本机切片，每片单独预算并持久保存以便续传；没有公开价格接口，Worker 使用配置的人民币价格表并冻结到每次报价；没有按 id 查询费用的接口，响应丢失的尝试保持“未确认”预留，由用户在控制台核对后处理，不会静默释放。

切换期间 Worker 同时接受旧的 OpenRouter 报价与结算，直到没有未结的 OpenRouter 尝试。此 ADR 记录设计决定；开发按 issue #34 的已批准计划进行。

预算与费用核对部分已由 [ADR 0004](0004-no-spending-tracking.md) 取代。
