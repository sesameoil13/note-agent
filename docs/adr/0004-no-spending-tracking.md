# 不再记录费用：阿里云账户余额是唯一上限

用户在 App 中不需要看到、设置或核对费用，实际费用在阿里云百炼控制台查看。因此去掉共享月预算的全部概念：Worker 的预算账本、价格表、预留与结算、月上限，以及 App 中的预估、确认发送、费用核对和“按控制台账单记录费用”。每次收集保存后自动整理（见 GLOSSARY “整理”），不再需要用户确认。

防止失控发送只靠逐项规则：每次收集自动发送一次，临时失败最多自动重试 3 次，已整理的收集不会再次发送，用户的修改只同步、不交给 AI。阿里云账户余额不足时，App 提示充值。录音与导入音频上限 5 分钟，与百炼单次转写上限一致。

曾考虑保留一个用户看不到的固定月上限作为安全阀，但用户选择彻底放弃预算概念。T13 与 T33 中的预算设计（ADR 0003 的“计入共享月预算”和控制台核对部分）因此作废；Worker 的预算表在备份后删除，只保留配对与待办同步。
