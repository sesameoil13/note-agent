# 保留 Obsidian 笔记同步，独立同步待办状态

用户以 Obsidian 笔记作为最终版本，要求 Android、macOS、Windows 都能提醒，并在各端完成或延后事项后尽快同步状态。决定继续使用现有官方 Obsidian Sync 同步笔记和附件，App 另用轻量端点协调待办状态、设备配对及共享预算；首版不承担完整笔记库同步或通用双向编辑器的职责。

只依赖笔记文件同步更简单，但常规 Sync 需要 Obsidian 运行，不能满足所有待办状态更新的及时性；自行接管完整笔记库同步则会增加全库冲突和附件管理成本。用户接受正文与音频晚于待办状态到达，以及离线端可能出现尚未取消的提醒。App 必须区分本机保存、待办状态同步与笔记同步，不得将其中一种完成显示成全部完成。

此 ADR 记录已经认可的设计取舍，不代表获得开发、部署或切换远程笔记库的授权。
