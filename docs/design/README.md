# Approved initial visual direction

The user approved these three product concepts as the initial visual baseline:

- [Desktop workspace](./concepts/rigid-body-desktop-v1.png)
- [Mobile capture, task note and reminder](./concepts/rigid-body-mobile-v1.png)
- [Confirmation queue and recycle bin](./concepts/rigid-body-states-v1.png)

When implementing appearance, read the [user-supplied visual brief](./visual-brief.md) together with the published product specification. The brief supplies visual constraints; its full concept-shot list is not an expansion of product scope. The specification and the user's later decisions govern behavior, note templates and development authorization.

Preserve the graphite/slate/bone base, acid focus and oxide destructive/overdue states, hard edges, an 8px lattice and clear high-definition user content. Generated mockup text, example times, balances and minor color inconsistencies are demonstration data. Future reminder times must not inherit an overdue color; property panels and extra note sections are not part of the approved templates.

RIGID BODY remains a visual direction name. These documents and images do not constitute App implementation or permission to begin it.
